## 📌 معرفی پروژه و چالش مدیریت کانال تلگرام

مدیریت یک کانال فعال در تلگرام معمولاً نیازمند صرف ساعت‌ها وقت روزانه برای بررسی ده‌ها کانال خبری، وبلاگ‌های تخصصی یا کانال‌های رقیب، گلچین کردن مطالب مفید، ویرایش و بازنویسی آن‌ها با لحن مناسب و انتشار طبق برنامه‌ریزی است.

ربات‌های معمولی تلگرام (Bot API) نمی‌توانند مطالب کانال‌های عمومی را بخوانند؛ مگر آنکه ادمین آن کانال‌ها باشند. این پروژه با استفاده از **کلاینت MTProto (کتابخانه Pyrogram)** به عنوان اکانت کاربری متصل می‌شود؛ بنابراین می‌تواند هر کانال عمومی تلگرام را بدون نیاز به دسترسی ادمین رصد کرده، مطالب مرتبط با کلیدواژه‌های شما را شناسایی، با مدل زبانی هوش مصنوعی بازنویسی و پس از تایید شما در کانالتان منتشر کند.

## 🌟 ویژگی‌های کلیدی و معماری سیستم

- **📡 رصد همزمان چندین کانال مبدا:**  
  امکان افزودن و حذف کانال‌های هدف در لحظه از طریق دستورات `/add_source` و `/remove_source`.
- **🔑 فیلترینگ هوشمند با کلیدواژه (Persian Normalization):**  
  تنظیم کلمات کلیدی مورد نظر (`/add_keyword`). تنها پست‌هایی که شامل حداقل یکی از کلمات کلیدی باشند پردازش می‌شوند. این بخش به طور خودکار حروف فارسی و عربی (`ي/ی` و `ك/ک`) و نیم‌فاصله‌ها را یکسان‌سازی می‌کند تا دقت جستجو ۱۰۰٪ باشد.
- **🧠 معماری ترکیبی هوش مصنوعی و موتور قالبی (Hybrid Rewriter):**  
  - **حالت هوش مصنوعی (LLM Mode):** اتصال به OpenAI، DeepSeek، OpenRouter یا Ollama برای بازنویسی حرفه‌ای، خلاصه‌سازی و تغییر لحن متن.
  - **حالت جایگزین قالبی (Rule-Based Fallback):** در صورت قطع بودن سرویس AI یا تنظیم نشدن کلید API، سیستم به‌صورت خودکار به موتور قالبی سوئیچ می‌کند که لینک‌ها و آیدی‌های رقیب را حذف، متن را مرتب و امضای کانال شما را به انتها اضافه می‌کند.
- **🛡 حالت بررسی ادمین با دکمه شیشه‌ای (`/mode review`):**  
  پست بازنویسی‌شده ابتدا به عنوان پیش‌نویس به پی‌وی ادمین ارسال می‌شود و شامل سه دکمهٔ تعاملی است:
  `[✅ انتشار در کانال]` | `[❌ رد کردن]` | `[🔄 بازنویسی مجدد با AI]`
- **⚡ حالت انتشار کاملاً خودکار (`/mode auto`):**  
  در صورت تمایل می‌توانید تعیین کنید که پست‌ها پس از بازنویسی، مستقیماً و بدون نیاز به تایید در کانال منتشر شوند.
- **📊 پایگاه داده SQLite و جلوگیری از ارسال تکراری:**  
  تمام شناسه‌های پردازش‌شده در دیتابیس (`aiosqlite`) ذخیره می‌شوند تا حتی در صورت ریستارت شدن ربات، یک پست دو بار منتشر نشود.
- **🆓 کاملاً رایگان و متن‌باز (Free & Open Source):**  
  استفاده، توسعه و استقرار این پروژه برای تمامی توسعه‌دهندگان آزاد و رایگان است.

## 🚀 راهنمای نصب و راه‌اندازی سریع (محلی و داکر)

### ۱. دریافت مشخصات API از تلگرام
1. وارد سایت [my.telegram.org](https://my.telegram.org/apps) شوید.
2. یک اپلیکیشن بسازید و مقادیر `API_ID` و `API_HASH` را یادداشت کنید.

### ۲. تنظیم متغیرهای محیطی
پروژه را کلون کرده و فایل تنظیمات نمونه را کپی کنید:

```bash
git clone https://github.com/mamadiezad/telegram-channel-curator.git
cd telegram-channel-curator
cp .env.example .env
```

فایل `.env` را ویرایش کرده و مشخصات کانال و کلیدهای خود را وارد کنید:
```ini
TELEGRAM_API_ID=12345678
TELEGRAM_API_HASH=your_telegram_api_hash
TARGET_CHANNEL=@MyTechNewsChannel
ADMIN_USER_ID=123456789
PUBLISHING_MODE=review
OPENAI_API_KEY=sk-your_api_key_here
LLM_MODEL_NAME=gpt-4o-mini
CHANNEL_SIGNATURE=@MyTechNewsChannel
```

### ۳. روش اول: اجرا روی سیستم محلی (با Makefile)

```bash
# ایجاد محیط مجازی و نصب کتابخانه‌ها
make install

# اجرای تست‌های خودکار
make test

# اجرای ربات
make run
```
*در اولین اجرا، تلگرام یک کد تایید برای اکانت شما ارسال می‌کند که با وارد کردن آن، فایل نشست (`.session`) ساخته می‌شود.*

### ۴. روش دوم: استقرار با Docker Compose

```bash
# ساخت و اجرای کانتینر در پس‌زمینه
docker-compose up -d --build

# مشاهده لاگ‌های زنده
docker-compose logs -f
```

## 💬 جدول دستورات مدیریتی ربات در تلگرام

کافی است هریک از دستورات زیر را **توسط اکانت ادمین** داخل چت با ربات یا Saved Messages ارسال کنید:

| دستور | پارامترها | مثال | توضیحات |
| :--- | :--- | :--- | :--- |
| `/add_source` | `<@channel>` | `/add_source @TechNewsFA` | افزودن کانال مبدا برای مانیتورینگ. |
| `/remove_source` | `<@channel>` | `/remove_source @TechNewsFA` | حذف کانال مبدا از لیست رصد. |
| `/list_sources` | *بدون پارامتر* | `/list_sources` | نمایش لیست تمامی کانال‌های مبدا تحت نظر. |
| `/add_keyword` | `<word>` | `/add_keyword پایتون` | افزودن کلمه کلیدی به فیلترها. |
| `/remove_keyword` | `<word>` | `/remove_keyword پایتون` | حذف کلمه کلیدی از فیلترها. |
| `/list_keywords` | *بدون پارامتر* | `/list_keywords` | نمایش کلیدواژه‌های فعال (در صورت خالی بودن، همه پست‌ها پردازش می‌شوند). |
| `/mode` | `<auto \| review>` | `/mode review` | تغییر حالت بین «انتشار خودکار» (`auto`) و «تایید ادمین با دکمه شیشه‌ای» (`review`). |
| `/set_prompt` | `<text>` | `/set_prompt متن را دوستانه بازنویسی کن` | تغییر دستورالعمل و پرامپت هوش مصنوعی در لحظه. |
| `/stats` | *بدون پارامتر* | `/stats` | نمایش آمار کلی پست‌های پردازش‌شده، منتشرشده، در انتظار و ردشده. |
| `/start` یا `/help` | *بدون پارامتر* | `/help` | نمایش راهنمای کامل استفاده داخل تلگرام. |

## ❓ سوالات متداول (FAQ - سئوشده)

### سوال ۱: آیا برای رصد کانال‌های دیگر باید حتماً ادمین آن کانال‌ها باشم؟
**پاسخ:** خیر؛ به دلیل استفاده از معماری MTProto Userbot، اکانت شما می‌تواند هر کانال عمومی تلگرام را بدون نیاز به دسترسی ادمین رصد کرده و مطالب جدید را استخراج کند.

### سوال ۲: اگر کلید API هوش مصنوعی (OpenAI / DeepSeek) نداشته باشم یا اینترنت سرور قطع شود چه اتفاقی می‌افتد؟
**پاسخ:** سیستم به طور خودکار به موتور قالبی (Rule-Based Rewriter) سوئیچ می‌کند. این موتور بدون نیاز به AI، تمامی لینک‌ها و آیدی‌های کانال رقیب را پاک کرده، هشتگ‌های مرتبط را اضافه و امضای کانال شما را به انتها متصل می‌کند تا روند کار کانال متوقف نشود.

### سوال ۳: مکانیزم تایید ادمین با دکمه شیشه‌ای چگونه کار می‌کند؟
**پاسخ:** زمانی که حالت انتشار روی `review` تنظیم باشد، هر مطلب مرتبطی که بازنویسی می‌شود به صورت کارت پیش‌نویس برای چت ادمین ارسال می‌شود. شما می‌توانید با زدن دکمهٔ **[✅ انتشار در کانال]** پست را فوراً در کانال هدف منتشر کنید، با **[❌ رد کردن]** آن را لغو کنید، یا با **[🔄 بازنویسی مجدد]** از هوش مصنوعی بخواهید متن جدیدی تولید کند.

### سوال ۴: چگونه از انتشار مطالب تکراری جلوگیری می‌شود؟
**پاسخ:** ربات تمام زوج‌های `(source_channel, source_msg_id)` را در دیتابیس SQLite ثبت می‌کند. حتی اگر ربات بارها ریستارت شود، هیچ پستی دو بار پردازش و منتشر نخواهد شد.
